TRACK TIMER v1.6.2 — by oToddy.mp4
Billable work-time tracking for Blender: auto-pause on lost focus
and idle time, parallel work steps, TXT/HTML/CSV reports.
Requires Blender 3.6+ (extension package needs 4.2+).

INSTALL — Blender 4.2 or newer (recommended):
1. Download add-on-track-timer-v1.6.2.zip (do NOT unzip it).
2. Edit > Preferences > Get Extensions > click the v menu (top right)
   > "Install from Disk..." > select the .zip > Install.
3. Enable "Track Timer" (use the search box if needed).
4. 3D Viewport > press N > open the "Track Timer" tab.

INSTALL — Blender 3.6 to 4.1 (legacy):
1. Edit > Preferences > Add-ons > v menu > "Install from Disk..."
2. Select track_timer_addon.py (the single .py file) > Install.
3. Enable "Track Timer", then open the N-panel tab as above.
